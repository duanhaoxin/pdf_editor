# 轻页 PDF

在浏览器里打开、编辑并导出 PDF 的本地工具。所有处理都在你的电脑上完成，**不会上传文件，也没有账号或统计**。

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 `http://127.0.0.1:4789`）。

生产构建：

```bash
npm run build
npm run preview
```

## 功能

- **打开**：拖放或选择一个或多个 PDF；多文件会按顺序合并。支持多页预览、缩略图和缩放。
- **页面编辑**：拖动缩略图排序、旋转、删除、插入空白页；提取所选页面；再合并其它 PDF。
- **内容批注**：文本框、高亮、下划线、手绘、矩形/椭圆/直线/箭头、图片、印章。文本框可「遮盖原文」后覆写。导出时批注会写入 PDF，不只是画在屏幕上。
- **工具**：拆分成多个 PDF（ZIP）、按清晰度压缩、提取文字、导出 PNG/JPEG。
- **导出**：下载编辑后的 PDF；会话内支持撤销 / 重做。
- **其它**：加密 PDF 会提示输入密码；大文件有进度提示；解析失败会给出明确错误。

首次使用可以点「打开示例文档」，会在浏览器里生成一份四页中文示例，无需准备自己的文件。你也可以用任意本地 PDF 测试。

## 不会做的事

- **不提供 Word / DOCX 导出**。把 PDF 可靠转成可编辑 Word 需要版式还原引擎，客户端难以做好，因此本版本没有做半成品转换。
- **不能真正改写 PDF 里原有的文字对象**。现有 PDF 文本通常是绘制指令而不是可编辑段落。请用文本框覆盖（可加白色遮盖）来修订。
- **内置中文字体覆盖常用汉字（GB2312）**。极生僻字导出时可能显示为「·」。
- 部分加密 PDF 在导出时可能被栅格化成图片页，以便保证能下载。

## 技术说明

Vite + React + TypeScript。页面渲染使用 [PDF.js](https://mozilla.github.io/pdf.js/)，写入与合并使用 [pdf-lib](https://pdf-lib.js.org/)。中文字体为 [Noto Sans SC](https://github.com/notofonts/noto-cjk) 子集（SIL Open Font License）。
